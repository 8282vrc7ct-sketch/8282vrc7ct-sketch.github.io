# 8282vrc7ct-sketch.github.io

## What this is
Your personal website: one page with About, Projects and Contact sections. The folder name is the web address GitHub Pages would use for it.

## Run it
In a Terminal tab in this folder:

```bash
open index.html
```

Your browser shows the page from this Mac. Only you can see it this way. Nothing here has been saved in Git or put online yet.

## Test it
No tests yet. To check by hand: click About, Projects and Contact at the top. Each should jump to its section.

## What's in this folder
- `index.html`: the words and sections of the page.
- `style.css`: colors, fonts and spacing.

## Try changing this
In `index.html`, find the line with `class="tagline"`. It still says "Warehouse pro". Change the words between `>` and `<` to match you today. Save and reload the page. The line under your name should change.

## Words to know
- **tag**: a label in angle brackets, like `<h1>`, that says what a piece of the page is.
- **stylesheet**: the CSS file that sets how the page looks.
- **GitHub Pages**: a free GitHub service that puts a folder like this online.
- **local**: on your own computer, not on the internet.
